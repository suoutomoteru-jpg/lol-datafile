# ガングプランク（大海原の大災厄）

- DDragon ID: `Gangplank`
- ロール: Fighter
- リソース: マナ
- patch: `16.17.1`

## パッシブ: 背水の銃剣

近接通常攻撃で対象に火を点け、2.5秒かけて50〜250（レベル比例） ＋ 増加攻撃力の100%の確定ダメージを追加で与える。また、2秒間、自身の移動速度が15〜30%（レベル比例）増加する。

「火薬樽」を破壊すると、このスキルのクールダウンが解消されて、同じように移動速度が増加する。

タワーに対するダメージは50%になる。
偽りの発砲ではこのスキルは適用されない。

## Q: 偽りの発砲

クールダウン: 4.5 / コスト: 50/45/40/35/30 / 射程: 625 / 最大ランク: 5

弾丸を発射し10/40/70/100/130（＋合計攻撃力の100%）の物理ダメージを与える。このスキルで対象を倒すと、追加で3/4/5/6/7ゴールドと4/5/6/7/8シルバーサーペントを獲得する。

シルバーサーペントはショップで「一斉砲撃」をアップグレードする際に使用する。
弾丸を発射し10/40/70/100/130（＋合計攻撃力の100%）の物理ダメージを与える。対象がチャンピオンの場合、与えたダメージの7%にあたるゴールドとシルバーサーペントを獲得する。このスキルで対象を倒すと、追加で3/4/5/6/7ゴールドと4/5/6/7/8シルバーサーペントを獲得する。

シルバーサーペントはショップで「一斉砲撃」をアップグレードする際に使用する。

奪ったゴールドの合計: 10/40/70/100/130ゴールド
奪ったシルバーサーペントの合計: 25%シルバーサーペント

## W: 壊血病治癒

クールダウン: 22/20/18/16/14 / コスト: 60/70/80/90/100 / 射程: 400 / 最大ランク: 5

オレンジを大量摂取して、行動妨害効果をすべて解除し、45/70/95/120/145（＋魔力の90%）(+減少体力の13%)を回復する。

## E: 火薬樽

クールダウン: 0 / 射程: 1000 / 最大ランク: 5

自身および敵チャンピオンが通常攻撃可能な「火薬樽」を25秒間設置する。敵が破壊した場合、樽はそのまま消滅する。自身が破壊した場合、樽は爆発して2秒間40/50/60/70/80%のスロウ効果を付与し、物理防御の40%を無視して通常攻撃のダメージを与える。チャンピオンに対しては、追加で75/95/115/135/155の物理ダメージを与える。

樽の体力は2/1/0.5（レベル1/7/13）秒ごとに減少していく。爆発した樽と爆発範囲が重なっている樽は誘爆するが、同じ対象には1回しかダメージを与えない。「偽りの発砲」による樽の爆発で対象を倒した場合、追加ゴールドを獲得する。

## R: 一斉砲撃

クールダウン: 160/140/120 / コスト: 100 / 射程: 30000 / 最大ランク: 3

海賊船に合図を送り、8秒かけてマップ上の任意の場所を12回砲撃させる。それぞれの砲撃で0.5秒間30%のスロウ効果と40/70/100（＋魔力の10%）の魔法ダメージを与える。最大ダメージ: 480/840/1200（＋魔力の10%）

このスキルは「偽りの発砲」で集めたシルバーサーペントを使ってショップでアップグレードできる。

乱れ撃ち: 砲撃回数が6回増加する。
死の女神: 巨大な砲弾を放ち、120/210/300（＋魔力の30%）の確定ダメージを与え、1秒間、75%のスロウ効果を付与する。
士気上昇: 2秒間、「一斉砲撃」の範囲内の味方の移動速度が40%増加する。
