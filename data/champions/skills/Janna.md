# ジャンナ（嵐の怒り）

- DDragon ID: `Janna`
- ロール: Support/Mage
- リソース: マナ
- patch: `16.16.1`

## パッシブ: テイルウィンド

ジャンナに向かって移動する際、味方チャンピオンは移動速度が6%増加する。

 通常攻撃時効果および「ゼファー」で、10/15/20/25/30の追加魔法ダメージを与える。

## Q: ハウリングゲイル

クールダウン: 14 / コスト: 90/95/100/105/110 / 射程: 1075 / 最大ランク: 5

竜巻を召喚する。竜巻は3秒かけて成長し、その後進路上にいる敵に55/90/125/160/195（＋魔力の50%） - 55/90/125/160/195（＋魔力の50% ＋3×10/15/20/25/30（＋魔力の10%））の魔法ダメージを与えて、50% - 1.25秒間ノックアップさせる。移動距離、ダメージ、ノックアップ時間は竜巻の成長に応じて増加する。再発動すると、即座に竜巻を送り出せる。

## W: ゼファー

クールダウン: 8/7.5/7/6.5/6 / コスト: 50/55/60/65/70 / 射程: -1 / 最大ランク: 5

自動効果: 移動速度が6/7/8/9/10%（＋魔力の0.02%）増加し、ゴースト化する。

発動効果: エレメントの力で敵を攻撃して2秒間20/24/28/32/36%（＋魔力の6%）のスロウ効果を付与し、55/85/115/145/175（＋魔力の50%） + 10/15/20/25/30の魔法ダメージを与える。

## E: ストームブレス

クールダウン: 16/15/14/13/12 / コスト: 70/75/80/85/90 / 射程: 800 / 最大ランク: 5

味方のチャンピオンまたはタワーに4秒間、耐久値80/120/160/200/240（＋魔力の55%）のシールドを付与する。シールド展開中の対象は攻撃力が10/15/20/25/30（＋魔力の10%）増加する。

敵チャンピオンにスキルで移動妨害効果を与えるたびにクールダウンが20%短縮される。

## R: モンスーン

クールダウン: 130/115/100 / コスト: 100 / 射程: 725 / 最大ランク: 3

魔法の嵐を召喚して、周囲の敵をノックバックさせ、3秒かけて周囲の味方の体力を300/450/600（＋魔力の50%）回復する。移動するかスキルを使用すると嵐が早めに終了する。
