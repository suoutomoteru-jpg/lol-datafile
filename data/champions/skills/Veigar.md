# ベイガー（小さき大魔王）

- DDragon ID: `Veigar`
- ロール: Mage
- リソース: マナ
- patch: `16.16.1`

## パッシブ: 偉大なる悪の力

スキルが敵チャンピオンに当たると「偉大なる悪の力」のスタックを1獲得する。チャンピオンからキルまたはアシストを獲得すると追加で5スタック獲得する。

「偉大なる悪の力」を1スタック獲得するごとに魔力が1増加する。

「偉大なる悪の力」で得た現在の魔力は1.5/1.75/2/2.25/2.5。

## Q: イーヴィルストライク

クールダウン: 6/5.5/5/4.5/4 / コスト: 30/35/40/45/50 / 射程: 1000 / 最大ランク: 5

闇のエネルギーを発射し、最初に命中した敵2体に80/120/160/200/240（＋魔力の50/55/60/65/70%）の魔法ダメージを与える。

このスキルで敵を倒すと「偉大なる悪の力」のスタックが1増加する。対象が大型ミニオン、大型モンスターの場合は代わりにスタックを3獲得する。

## W: ダークマター

クールダウン: 0 / コスト: 60/65/70/75/80 / 射程: 950 / 最大ランク: 5

ダークマターを落下させて、85/140/195/250/305（＋魔力の70/80/90/100/110%）の魔法ダメージを与える。

「偉大なる悪の力」のスタックが50たまるごとに、このスキルのクールダウンが10%短縮される。

現在のクールダウン短縮割合: 120%

## E: イベントホライズン

クールダウン: 20/18.5/17/15.5/14 / コスト: 70/75/80/85/90 / 射程: 725 / 最大ランク: 5

空間の境界をねじ曲げて檻を作り出す。檻を通過した敵は1.5/1.75/2/2.25/2.5秒間スタン効果を受ける。檻は3秒間持続する。

## R: メテオバースト

クールダウン: 120/90/60 / コスト: 100 / 射程: 650 / 最大ランク: 3

敵チャンピオン1体に闇の大魔法を放ち、対象の減少体力に応じて175/250/325（＋魔力の65/70/75%）-350/500/650（＋魔力の65/70/75%）の魔法ダメージを与える。ダメージは敵の体力が33%を下回ると最大になる。
