# タリヤ（ストーンウィーバー）

- DDragon ID: `Taliyah`
- ロール: Mage/Support
- リソース: マナ
- patch: `16.17.1`

## パッシブ: ロックサーフィン

非戦闘状態で壁の近くに3秒以上いると、移動速度が10/15/25/40%（レベル1/9/12/15）増加する。

## Q: スレッドボレー

クールダウン: 7/6/5/4/3 / コスト: 55/60/65/70/75 / 射程: 1000 / 最大ランク: 5

指定方向に5個の石を投げる。それぞれの石は最初に命中した敵の周囲に55/72.5/90/107.5/125（＋魔力の50%）の魔法ダメージを与え、その地点に「加工された地面」を作り出す。同じ敵に連続で命中すると、ダメージが60%低下する。

「加工された地面」の上で発動する場合、マナコストが10になり、クールダウンが50%短縮され、その「加工された地面」を消費して大きな石を1発投げる。この石は命中したすべての敵に1.5秒間、20/25/30/35/40%のスロウ効果を付与し、最初に命中した対象には99/130.5/162/193.5/225（＋魔力の50%）の魔法ダメージを与える。大きな石が命中したモンスターは3秒間スタン状態になる。

## W: サイズミックシャーブ

クールダウン: 14/12.5/11/9.5/8 / コスト: 40/30/20/10/0 / 射程: 900 / 最大ランク: 5

地面を歪ませて、範囲内の敵を指定方向にノックバックさせる。

## E: アンレイベルアース

クールダウン: 14 / コスト: 90 / 射程: 950 / 最大ランク: 5

一定範囲に不安定な石をばら撒き、触れた敵に20%のスロウ効果を付与して、60/105/150/195/240（＋魔力の60%）の魔法ダメージを与える。ばら撒いた石の上を敵がダッシュするかノックバックされて通過すると石が爆発し、0.75秒間(+その移動の残り時間)スタンさせて、25/40/55/70/85（＋魔力の30%）の魔法ダメージを与える。

## R: ウィーバーウォール

クールダウン: 180/150/120 / コスト: 100 / 射程: 2500/4500/6500 / 最大ランク: 3

4秒間、巨大な土壁を作り出す。スキルを即座に再発動すると、タリヤは展開される壁に沿って移動する。移動するか移動不能効果を受けると壁から降りる。

チャンピオンまたは建造物によるダメージを受けてから3秒間は、このスキルを使用できない。
