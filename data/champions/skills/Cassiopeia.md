# カシオペア（毒蛇の抱擁）

- DDragon ID: `Cassiopeia`
- ロール: Mage
- リソース: マナ
- patch: `16.17.1`

## パッシブ: 妖艶な蛇行

カシオペアはあらゆる移動速度増加効果の効率が6〜40%（レベル1〜18）増加する。

## Q: ノクサスブラスト

クールダウン: 3.5 / コスト: 50/55/60/65/70 / 射程: 850 / 最大ランク: 5

毒ガスを噴出させて敵を毒状態にし、3秒かけて75/110/145/180/215（＋魔力の65%）の魔法ダメージを与える。チャンピオンに当たると自身の移動速度が30/35/40/45/50%増加する。この移動速度は3秒かけて元に戻る。

## W: ミアズマ

クールダウン: 24/22/20/18/16 / コスト: 70/75/80/85/90 / 射程: 700 / 最大ランク: 5

毒を吐き、5秒間持続する毒霧を発生させる。毒霧の中にいる敵は毎秒20/25/30/35/40（＋魔力の10%）の魔法ダメージを受けて毒状態になり、釘付け効果と40/50/60/70/80%のスロウ効果を受ける。

## E: ツインファング

クールダウン: 0.75 / コスト: 40 / 射程: 700 / 最大ランク: 5

鋭利な牙を飛ばして52〜120（レベル1〜18） ＋ 魔力の10%の魔法ダメージを与える。敵が毒状態の場合、20/45/70/95/120（＋魔力の55%）の魔法ダメージを追加で与えて、自身の体力を魔力の10/11.5/13/14.5/16%回復する。対象がレーンミニオンや小型モンスターの場合、体力回復量が魔力の10/11.5/13/14.5/16%×0.25に減少する。

このスキルで対象をキルすると、マナが40回復する。

## R: 石化の魔眼

クールダウン: 120/100/80 / コスト: 100 / 射程: 825 / 最大ランク: 3

「石化の魔眼」を開放し、150/250/350（＋魔力の50%）の魔法ダメージを与えて、自身の方を向いている敵を2秒間スタンさせる。自身に背を向けている敵には40%のスロウ効果を与える。この効果は同じ効果時間をかけて元に戻る。
