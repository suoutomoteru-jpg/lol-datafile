# ゼラス（超越魔神）

- DDragon ID: `Xerath`
- ロール: Mage/Support
- リソース: マナ
- patch: `16.16.1`

## パッシブ: マナサージ

16秒ごとに、次にチャンピオンに対して行う通常攻撃で30〜195（レベル1〜18）×2マナを回復する。対象がミニオン、ジャングルモンスター、建造物だった場合は30〜195（レベル1〜18）マナを回復する。

ユニットをキルするたびに、このクールダウンが3.5秒短縮される。

## Q: アルカノパルス

クールダウン: 9/8/7/6/5 / コスト: 80/90/100/110/120 / 射程: 750 / 最大ランク: 5

チャージ開始: 蒼いビームのチャージを開始して、自身の移動速度が最大50%まで徐々に低下する。

解放: ビームを発射して75/115/155/195/235（＋魔力の90%）の魔法ダメージを与える。チャージした時間に応じて射程が増加する。

## W: デストラクションアイ

クールダウン: 14/13/12/11/10 / コスト: 80/90/100/110/120 / 射程: 1000 / 最大ランク: 5

神秘のエネルギーを空から降らせて50/85/120/155/190（＋魔力の65%）の魔法ダメージを与え、2.5秒間25%のスロウ効果を付与する。効果範囲の中心にいた敵には代わりに83.35/141.695/200.04/258.385/316.73（＋魔力の65%）の魔法ダメージを与え、60/65/70/75/80%のスロウ効果を付与する。この効果は2.5秒かけて元に戻る。

## E: ショックオーブ

クールダウン: 13/12.5/12/11.5/11 / コスト: 60/65/70/75/80 / 射程: 1050 / 最大ランク: 5

荒れ狂う魔力の弾を放ち、弾の移動距離に応じて最初に当たった敵を最大2.25秒間スタンさせて、70/100/130/160/190（＋魔力の45%）の魔法ダメージを与える。

## R: アーケーンライト

クールダウン: 130/115/100 / コスト: 100 / 射程: 5000 / 最大ランク: 3

魔力を開放して真の姿をあらわし、10秒間詠唱する。この間、最大4/5/6回まで再発動できる。

再発動: 魔弾を発射して170/220/270（＋魔力の45%）の魔法ダメージを与える。チャンピオンに命中するたび、魔弾が追加で20/25/30（＋魔力の5%）の魔法ダメージを与える。
