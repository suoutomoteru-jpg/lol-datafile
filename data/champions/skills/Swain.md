# スウェイン（ノクサス帝国元帥）

- DDragon ID: `Swain`
- ロール: Mage/Support
- リソース: マナ
- patch: `16.17.1`

## パッシブ: 恐襲の魔鴉

鴉たちが「魂のかけら」を回収し、スウェインの体力を回復して、最大体力を恒久的に上昇させる。

詳細数値
・回復: 6〜6%（レベル比例）
・回復: 6〜6%（レベル比例）×合計体力の100%

## Q: 死の手

クールダウン: 7/6/5/4/3 / コスト: 40/45/50/55/60 / 射程: 750 / 最大ランク: 5

この世ならざる力の稲妻を5本発射して60/90/120/150/180（＋魔力の45%）の魔法ダメージを与える。同じ敵に複数の稲妻が命中した場合、2本目以降の稲妻は1本あたり15/22.5/30/37.5/45（＋魔力の45%）の魔法ダメージを与える(最大120/180/240/300/360（＋魔力の45%）の魔法ダメージ)。

## W: 帝国の眼

クールダウン: 22/21/20/19/18 / コスト: 60/65/70/75/80 / 射程: 5500/6000/6500/7000/7500 / 最大ランク: 5

悪魔の眼を開いて1.5秒間指定地点の視界を得て、70/105/140/175/210（＋魔力の60%）の魔法ダメージを与え、1.5秒間50%のスロウ効果を付与する。

爆発が当たったチャンピオン1体につき「魂のかけら」を1個獲得する。爆発が当たった敵チャンピオンは6秒間可視化される。

## E: 束縛の爪

クールダウン: 12/11.5/11/10.5/10 / コスト: 50/55/60/65/70 / 射程: 850 / 最大ランク: 5

悪魔のエネルギー波を発射する。その後、エネルギー波を呼び戻し、最初に当たった敵のところで爆発させ、90/130/170/210/250（＋魔力の70%）の魔法ダメージと、爆発の範囲内にいた敵に1.5秒間のスネア効果を与える。

チャンピオンにスネア効果を与えた場合、このスキルを再発動することで、「束縛の爪」によりスネア効果を与えたすべてのチャンピオンを自身の方向に引き寄せることができる。また、引き寄せた敵1体につき「魂のかけら」を1個獲得する。

## R: 魔帝戴冠

クールダウン: 120 / コスト: 100 / 射程: 650 / 最大ランク: 3

悪魔を解放して毎秒15/25/35（＋魔力の4%）の魔法ダメージを与え、さらに付近の敵から毎秒15/30/45（＋魔力の5% ＋増加体力の1.5%）の体力を吸収する。悪魔のエネルギーは徐々に減少するが、敵チャンピオンから体力を吸収することで無限にチャージ可能で、チャンピオンからキルまたはアシストを獲得すると最大まで回復する。

2秒後、そしてその後8秒ごとに、変身中「悪魔の紅炎」が発動可能になり、敵に150/250/350（＋魔力の40%）の魔法ダメージと50%のスロウ効果を与える。この効果は1.5秒かけて元に戻る。
