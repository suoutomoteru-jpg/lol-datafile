# ツイステッド・フェイト（不敗のイカサマ師）

- DDragon ID: `TwistedFate`
- ロール: Mage/Marksman
- リソース: マナ
- patch: `16.17.1`

## パッシブ: イカサマダイス

ユニットを1体倒すたびに「幸運のサイコロ」を振り、1～6の追加ゴールドを獲得する。
敵チャンピオンにダメージを与えると、与えたダメージの2%から8%にあたる、ランダムな量のボーナスゴールドを獲得する。

## Q: ワイルドカード

クールダウン: 6/5.75/5.5/5.25/5 / コスト: 60/70/80/90/100 / 射程: 10000 / 最大ランク: 5

3枚のカードを投げ、それぞれが60/105/150/195/240（＋増加攻撃力の50% ＋魔力の85%）の魔法ダメージを与える。

## W: ドロー

クールダウン: 6 / コスト: 50/55/60/65/70 / 射程: 200 / 最大ランク: 5

カードのシャッフルを開始し、再発動で3枚のカードから1枚ピックする。選んだカードによって、次の通常攻撃に異なる効果が付与される。

・ブルーカードはの魔法ダメージを与えて、マナを70/90/110/130/150回復する。
・レッドカードは周囲の敵にの魔法ダメージを与えて、2.5秒間30/35/40/45/50%のスロウ効果を付与する。
・ゴールドカードはの魔法ダメージを与えて、1/1.25/1.5/1.75/2秒間スタンさせる。

## E: スタックデッキ

クールダウン: 0 / 射程: 0 / 最大ランク: 5

自動効果: 攻撃速度が15/25/35/45/55%増加する。また、通常攻撃4回ごとに65/90/115/140/165（＋増加攻撃力の20% ＋魔力の40%）の魔法ダメージを追加で与える。

## R: デスティニー

クールダウン: 170/140/110 / コスト: 100 / 射程: 5500 / 最大ランク: 3

カードに意識を集中し、6/8/10秒間マップ上にいるすべての敵チャンピオンの真の視界を得て、再発動が可能になる。

再発動: 距離5500ユニット以内の場所にワープする。
