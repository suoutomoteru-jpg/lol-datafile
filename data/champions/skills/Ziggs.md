# ジグス（ヘクス爆薬のエキスパート）

- DDragon ID: `Ziggs`
- ロール: Mage
- リソース: マナ
- patch: `16.17.1`

## パッシブ: ショートヒューズ

秒ごとに、次の通常攻撃が追加で20〜160（レベル1〜18） ＋ 魔力の50%の魔法ダメージを与える。建造物には20〜160（レベル1〜18） ＋ 魔力の50%×1.75のダメージを与える。

スキルを使用すると次の追加ダメージまでの時間を4/5/6（レベル1/7/13）秒短縮する。

## Q: バウンドボム

クールダウン: 6/5.5/5/4.5/4 / コスト: 50/55/60/65/70 / 射程: 850 / 最大ランク: 5

地面にバウンドする爆弾を投げ、80/130/180/230/280（＋魔力の60/65/70/75/80%）の魔法ダメージを与える。

## W: エンジニアボム

クールダウン: 20/18/16/14/12 / コスト: 80 / 射程: 1000 / 最大ランク: 5

発動の4秒後、またはこのスキルを再発動した時に起爆するヨードルグレネードを投げる。敵に70/105/140/175/210（＋魔力の50%）の魔法ダメージを与えてノックバックさせる。ジグスも弾き飛ばされるがダメージは受けない。

「エンジニアボム」は体力が25/27.5/30/32.5/35%未満のタワーを自動的に破壊する。

## E: ヘクステックマイン

クールダウン: 16 / コスト: 70/80/90/100/110 / 射程: 900 / 最大ランク: 5

地面に地雷を複数設置する。敵が接触すると爆発し、30/70/110/150/190（＋魔力の25/30/35/40/45%）の魔法ダメージと1.5秒間10/20/30/40/50%のスロウ効果を与える。地雷は10秒間持続する。

## R: メガインフェルノボム

クールダウン: 120/95/70 / コスト: 100 / 射程: 5000 / 最大ランク: 3

究極の発明品を投げ、爆発範囲の中心部では300/500/700（＋魔力の100%）の魔法ダメージを、その周辺では195/325/455（＋魔力の100%）の魔法ダメージを与える。
