# ラカン（魅惑の翼）

- DDragon ID: `Rakan`
- ロール: Support
- リソース: マナ
- patch: `16.16.1`

## パッシブ: 神秘の翼

40〜14.5（レベル1〜18）秒ごとに30〜225（レベル比例） ＋ 魔力の95%のシールドを獲得する。敵チャンピオンに通常攻撃かスキルを使用すると、このクールダウンが1秒短縮される。

愛の跳躍 - ザヤとラカンは一緒にリコールできる。

## Q: キラリ羽根

クールダウン: 11/10/9/8/7 / コスト: 45 / 射程: 850 / 最大ランク: 5

魔法の羽根を投げて、最初に当たった敵ユニットに70/115/160/205/250（＋魔力の70%）の魔法ダメージを与える。

羽根がチャンピオンかエピックジャングルモンスターに当たると、3秒後、または自身が味方チャンピオンに触れた時に、自身と周囲の味方の体力を40〜210（レベル比例） ＋ 魔力の55%回復する。

## W: 華麗なる登場

クールダウン: 14/13/12/11/10 / コスト: 50/60/70/80/90 / 射程: 600 / 最大ランク: 5

ダッシュしてから回転して宙に舞い上がり、1秒間ノックアップさせて70/120/170/220/270（＋魔力の80%）の魔法ダメージを与える。

## E: バトルダンス

クールダウン: 0 / コスト: 40/45/50/55/60 / 射程: 650 / 最大ランク: 5

味方チャンピオンのところまでダッシュして、3秒間耐久値50/75/100/125/150（＋魔力の70%）のシールドを付与する。

このスキルは5秒以内なら一度だけ再発動できる。

## R: みんなオレに夢中

クールダウン: 130/110/90 / コスト: 100 / 射程: 150 / 最大ランク: 3

4秒間、移動速度が75%増加する。自身が触れた敵に初回のみ100/200/300（＋魔力の50%）の魔法ダメージと1/1.25/1.5秒間のチャーム効果を与える。最初にチャンピオンに触れたときには、自身の移動速度が150%増加し、徐々に元に戻る。
