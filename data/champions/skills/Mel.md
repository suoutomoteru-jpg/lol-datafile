# メル（魂の反照）

- DDragon ID: `Mel`
- ロール: Mage/Support
- リソース: マナ
- patch: `16.17.1`

## パッシブ: 灼熱の輝き

通常攻撃とスキルで敵にダメージを与えるたびに、5秒間「圧倒」のスタックを付与し、スタックをリフレッシュする。60/70/80/90/100/110（＋魔力の10%） + スタックごとに3/4/5/6/7/8（＋魔力の0.75%）の魔法ダメージを蓄積させる。スタックが適用されている間は、蓄積されたダメージ量が敵のシールドと体力の合計値を超えた時点で敵にとどめを刺す。

スキルを使用すると、次の通常攻撃が3発の飛翔物を追加で発射し、それぞれが8〜30（レベル比例） ＋ 魔力の4%の魔法ダメージを与える。追加の飛翔物は最大で9発までスタックする。

ミニオンに使用した場合、「圧倒」の最初のスタックはダメージが50%低下する。

## Q: 輝きの連撃

クールダウン: 10/9/8/7/6 / コスト: 70/75/80/85/90 / 射程: 950 / 最大ランク: 5

指定地点に向かって6/7/8/9/10発の飛翔物を連続で発射する。飛翔物は指定地点の周囲に爆発を引き起こす。

最初の爆発の命中時に60/85/110/135/160（＋魔力の55%）の魔法ダメージを与え、その後の爆発はそれぞれ5/7/9/11/13（＋魔力の5%）の魔法ダメージ、最大で合計の魔法ダメージを与える。

## W: 反駁

クールダウン: 38/35/33/29/26 / コスト: 80/60/40/20/0 / 射程: 250 / 最大ランク: 5

自身の周囲にバリアを形成する。このバリアは敵チャンピオンの発射物を反射し、耐久値80/110/140/170/200（＋魔力の70%）のシールドを0.75秒間獲得する。また、自身の移動速度を40%増加させる。この移動速度は0.75秒かけて元に戻る。

反射された発射物は元のダメージの40/45/50/55/60%を魔法ダメージとして与える。

## E: 陽光の枷

クールダウン: 11/10.5/10/9.5/9 / コスト: 50/60/70/80/90 / 射程: 1000 / 最大ランク: 5

輝くオーブを発射し、中心にいた敵には1.5秒間、スネア効果を与え、60/105/150/195/240（＋魔力の70%）の魔法ダメージを与える。

オーブは周囲に敵対的範囲を作り出し、敵に30%のスロウ効果を与えて、毎秒16/28/40/52/64（＋魔力の8%）の魔法ダメージを与える。

## R: 黄金蝕

クールダウン: 120/100/80 / コスト: 100 / 射程: 25000 / 最大ランク: 3

自動効果: 「圧倒」のダメージが60/70/80（＋魔力の10%） + スタックごとに3/4/5（＋魔力の0.75%）の魔法ダメージに増加する。

発動効果: 「圧倒」を付与されたすべての敵に向けてパワーを解き放ち、125/200/275（＋魔力の30%） + 「圧倒」のスタックごとに4/7/10（＋魔力の4%）の魔法ダメージを与える。

敵チャンピオンに「圧倒」が付与されていない時は使用できない。
