# ヨリック（魂の導き手）

- DDragon ID: `Yorick`
- ロール: Fighter/Tank
- リソース: マナ
- patch: `16.17.1`

## パッシブ: 魂の導き手

周囲で敵が8〜2（レベル1〜18）体倒されるたびに墓が作られる。チャンピオンと大型モンスターは常に墓を残す。

これらはエリア内に最大4体まで、「ミストウォーカー」を「目覚め」させるために使用される。「ミストウォーカー」は体力が100〜300（レベル比例） ＋ 増加体力の15%、攻撃力が15〜100（レベル比例） ＋ 増加攻撃力の20%。

「ミストウォーカー」
建造物には50%のダメージを与える。
ジャングルモンスターには60%のダメージを与える。
近接攻撃チャンピオンの通常攻撃から200%のダメージを受ける。
範囲ダメージからは66〜32%（レベル1〜18）のダメージを受ける。
レーンミニオンからは60%のダメージを受ける。
ジャングルモンスターからは100%のダメージを受ける。

## Q: 葬送

クールダウン: 6/5.5/5/4.5/4 / コスト: 20 / 射程: 0 / 最大ランク: 5

次の通常攻撃が追加で30/50/70/90/110（＋合計攻撃力の50%）の物理ダメージを与え、10〜68（レベル1〜18） + 自身の減少体力の6/7/8/9/10%の体力を回復する。チャンピオン以外に対しては回復量が50%低下する。この通常攻撃がチャンピオンまたは大型モンスターに命中するか、対象を倒すと、墓が残る。

周囲に3つ以上の墓が存在し、このスキルが使用されていた場合は、再発動すると周囲の墓から「ミストウォーカー」を召喚できる。

## W: 屍の列

クールダウン: 20/18/16/14/12 / コスト: 70 / 射程: 600 / 最大ランク: 5

霊の壁を召喚する。敵はこの壁を通り抜けられないが、味方は通り抜けられる。壁の体力は2/2/3/3/4で、4秒後に消滅する。

## E: 悲嘆の霧

クールダウン: 12/11/10/9/8 / コスト: 50/55/60/65/70 / 射程: 700 / 最大ランク: 5

「黒き霧」の塊を投げつけて最大体力の6/6.5/7/7.5/8%（＋魔力の3%）にあたる魔法ダメージを与え、1.5秒間30%のスロウ効果を付与し、4秒間チャンピオンとモンスターをマークする。マークされた敵は継続的に周囲の墓を「目覚め」させ(最大召喚数である4体は越えない)、物理防御が13/16/19/22/25%低下する。

自身と召喚したユニットは、マークされた対象に向かう際に移動速度が18/21/24/27/30%増加する。「ミストウォーカー」はマークされた敵が逃げると1回だけ飛びついて追いかける。

## R: 嘆きの墓標

クールダウン: 160/130/100 / コスト: 100 / 射程: 600 / 最大ランク: 3

体力1050〜3200（レベル1〜18） ＋ 増加体力の60%、魔法攻撃力50/75/100（＋増加攻撃力の30%）の「霧の乙女」と2/3/4体の「ミストウォーカー」を召喚する。「霧の乙女」は周囲で倒された敵から自動的に「ミストウォーカー」を召喚し、攻撃時に敵チャンピオンをマークする。「霧の乙女」が攻撃している対象を自身が攻撃すると、最大体力の2/2.5/3%にあたる魔法ダメージを与える。

10秒後、このスキルを再発動すると「霧の乙女」が解放されて、最も近いレーンを進んでいく。
