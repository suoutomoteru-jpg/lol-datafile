# ザイラ（茨の目覚め）

- DDragon ID: `Zyra`
- ロール: Mage/Support
- リソース: マナ
- patch: `16.16.1`

## パッシブ: 茨の楽園

13.6〜9.05（レベル比例）秒ごとに自身の周囲に30秒間持続する種を発生させる。同時に最大8個まで種を発生させられる。種は敵チャンピオンに踏まれると破壊される。自身が茂みに隠れている間は種は発生しない。

種は他のスキルで使用され、植物を発生させて15〜75（レベル比例） ＋ 魔力の20%の魔法ダメージを与える。

ザイラの植物は、モンスターに対して50〜100（レベル比例）の追加魔法ダメージを与える。

## Q: 死華の棘

クールダウン: 7/6.5/6/5.5/5 / コスト: 55 / 射程: 800 / 最大ランク: 5

複数の太いツルが広がって鋭い棘を生やし、60/100/140/180/220（＋魔力の65%）の魔法ダメージを与える。

このスキルを種の近くで使用すると、種が成長して「棘吹草」になる。「棘吹草」は15〜75（レベル比例） ＋ 魔力の20%の魔法ダメージを与え、8秒間持続する。「棘吹草」は575の射程を持つ。

## W: 狂い咲き

クールダウン: 0 / 射程: 850 / 最大ランク: 5

60秒間持続する種を植える。敵チャンピオンが種を踏むと、2秒間対象の真の視界を得るが、種は破壊される。

このスキルは2つまでチャージでき、秒で1つリチャージされる。敵のミニオンまたはモンスターをキルすると、リチャージ時間が35%短縮される。チャンピオンからキルまたはアシストを奪うと、代わりにリチャージ時間が100%短縮される。

## E: 捕縛の根

クールダウン: 11 / コスト: 70/75/80/85/90 / 射程: 1100 / 最大ランク: 5

前方にツルを送り出し、1/1.25/1.5/1.75/2秒間スネア効果を与えて、60/95/130/165/200（＋魔力の60%）の魔法ダメージを与える。

このスキルが近くの種に触れると、種が成長して「棘鞭草」になり、15〜75（レベル比例） ＋ 魔力の20%の魔法ダメージを与える。「棘鞭草」は8秒間持続し、射程が400で、通常攻撃が2秒間30%のスロウ効果を与える。複数の「棘鞭草」が与えたスロウ効果は最大2回までスタックする。

## R: 茨のゆりかご

クールダウン: 110/100/90 / コスト: 100 / 射程: 700 / 最大ランク: 3

大自然の怒りを呼び覚まし、茨を成長させて200/300/400（＋魔力の70%）の魔法ダメージを与える。2秒後にツルが跳ね上がり、1秒間ノックアップさせる。

茨に接触した植物は怒り狂い、効果時間がリセットされて、50%の体力を獲得し、通常攻撃で50%の追加ダメージを与える。
