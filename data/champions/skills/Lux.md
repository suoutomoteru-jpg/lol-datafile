# ラックス（光の才女）

- DDragon ID: `Lux`
- ロール: Mage/Support
- リソース: マナ
- patch: `16.16.1`

## パッシブ: イルミネーション

攻撃スキルが6秒間マークを付与する。通常攻撃でマークを消費して300/400/500（＋魔力の120%）の魔法ダメージを与える。

「ファイナルスパーク」を命中させた場合は敵のマークを消費したうえで再びマークを付与する。

## Q: ライトバインド

コスト: 50 / 射程: 1175 / 最大ランク: 5

光の玉を発射し、最初に命中した2体の敵に80/120/160/200/240（＋魔力の75%）の魔法ダメージと2秒間のスネア効果を付与する。

## W: プリズムバリア

クールダウン: 12/11.5/11/10.5/10 / コスト: 60/65/70/75/80 / 射程: 1150 / 最大ランク: 5

杖を投げて、それに触れた味方に2.5秒間40/55/70/85/100（＋魔力の40%）のシールドを付与する。杖が戻ってくる際も同量のシールドを付与する。

## E: シンギュラリティ

クールダウン: 10/9.5/9/8.5/8 / コスト: 70/80/90/100/110 / 射程: 1100 / 最大ランク: 5

光の領域を作り出し、範囲内の敵に25/30/35/40/45%のスロウ効果を与えて視界を得る。5秒経過するか再発動で爆発し、65/115/165/215/265（＋魔力の80%）の魔法ダメージを与えてスロウ効果を追加で1秒間付与する。

## R: ファイナルスパーク

クールダウン: 60/50/40 / コスト: 100 / 射程: 3340 / 最大ランク: 3

まばゆい光線を発射し、直線上の敵に300/400/500（＋魔力の120%）の魔法ダメージを与える。
