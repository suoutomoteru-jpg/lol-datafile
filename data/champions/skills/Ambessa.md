# アンベッサ（戦乱の母）

- DDragon ID: `Ambessa`
- ロール: Fighter/Assassin
- リソース: 気
- patch: `16.16.1`

## パッシブ: ドレイクハウンドの猛攻

スキル発動時に通常攻撃か移動操作をすると、スキル使用後にその方向にダッシュする。

スキルの詠唱を開始するごとに、4秒のチャージを付与する(最大3)。チャージ中、射程距離が75 、攻撃速度が50% 増加する。通常攻撃はチャージを1つ消費して5〜30（レベル比例） ＋ 増加攻撃力の25%の物理ダメージを与え、40/55/70（レベル1/7/13）の気を回復する。

詠唱時間、スキルの効果時間、または攻撃中に発された指示は保存される。スキルまたは攻撃が終了すると、一番最近保存された指示が実行される。チャージ攻撃の予備動作はキャンセルできない。スキル詠唱中に攻撃指示を発した後に停止指示を発すると、ダッシュがキャンセルされるが、ターゲットが射程範囲内にいる場合は攻撃指示は維持される。

## Q: カニングスイープ/サンダリングスラム

クールダウン: 14/13/12/11/10 / コスト: 70 / 射程: 650 / 最大ランク: 5

カニングスイープ: 両手の武器を自身の前方に向かって振り回し、範囲の最端部にいる敵に40/60/80/100/120（＋増加攻撃力の60%） + 最大体力の4/4.5/5/5.5/6%の物理ダメージを与える。その他の敵はすべて50%のダメージを受ける。その後「サンダリングスラム」を構える。

サンダリングスラム: 敵に刃を叩きつけ、最初に当たった敵に50/75/100/125/150（＋増加攻撃力の90%） + 最大体力の4/4.5/5/5.5/6%の物理ダメージを与える。その他の敵はすべて50%のダメージを受ける。

## W: 断交

クールダウン: 18/17/16/15/14 / コスト: 70 / 射程: 325 / 最大ランク: 5

1.5秒間50〜320（レベル比例） ＋ 増加攻撃力の150%のシールドを獲得し、0.5秒間構える。その後地面を叩きつけ、周囲の敵に50/75/100/125/150（＋増加攻撃力の50%）の物理ダメージを与える。敵チャンピオン、大型モンスター、建造物からのダメージをブロックしていた場合、周囲の敵への物理ダメージは75/112.5/150/187.5/225（＋増加攻撃力の50%）に増加する。

## E: ラセレイト

クールダウン: 13/12/11/10/9 / コスト: 70 / 射程: 325 / 最大ランク: 5

周囲に鎖を振り回し、40/60/80/100/120（＋増加攻撃力の50%）の物理ダメージを与え、99%のスロウ効果を与える(1秒かけて徐々に戻る)。このスキルから 「 ドレイクハウンドの猛攻 」 を発動すると、もう一度攻撃する。

## R: 公開処刑

クールダウン: 130/115/100 / 射程: 1250 / 最大ランク: 3

自動効果: 10/20/30%の 物理防御貫通を獲得し、スキルで自身が与えたダメージのを回復する。

発動効果: アンストッパブル状態となり、直線上の最も遠い敵チャンピオンにブリンクし、対象に0.75秒間サプレッション効果を与え、地面に叩きつけて150/250/350（＋増加攻撃力の80%）の物理ダメージと0.4秒間のスタン効果を与える。
